# MoreFindablePotions
This mod allows several of the base game Potions to spawn naturally, sometimes in place of a Teleport potion.  
This mod needs to be on the Server only.  
Requires https://github.com/CG-Nik/CustomDistributionAPI.  

This mod is not an API mod, there is already an existing Distribution for this.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
